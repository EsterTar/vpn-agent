# Backlog

Нереализованные фичи и известные ограничения.

---

## Ограничение устройств

Нет контроля, что одна подписка используется с одного устройства. Один `sub_token` работает на нескольких устройствах одновременно. В старой системе был `limit_ip` через 3X-UI — в новой это убрано.

**Варианты решения:** sing-box не имеет встроенного limit_ip. Нужен либо внешний мониторинг подключений, либо rate limiting на уровне агента.

---

## Разделение тестовых и продакшн конфигов

Все inbound-ы попадают в подписку всех клиентов. Нет способа отделить экспериментальный inbound (для тестирования нового протокола) от продакшн-конфигов, которые видят пользователи.

**Варианты решения:** добавить поле `is_test` к inbound-ам, или группы клиентов (тестеры vs обычные), или отдельные подписки (test sub_token + prod sub_token).

---

## Мониторинг и метрики

Нет сбора метрик: количество подключений, трафик, нагрузка на серверы, latency. Есть только `GET /api/health` (жив/не жив sing-box).

**Варианты решения:** sing-box умеет отдавать Prometheus-метрики (`experimental.clash_api` или `experimental.v2ray_api`). Нужен Prometheus + Grafana или аналог.

---

## Админка (Web UI)

Сейчас управление только через API + CLI. Нет веб-интерфейса для просмотра серверов, клиентов, подключений.

**Варианты решения:** простой фронтенд на React/Vue, или Telegram-бот как основной интерфейс.

---

## Telegram-бот

Нет интеграции с Telegram. Планируется бот для:
- Выдачи подписок
- Продления
- Просмотра статуса
- (Опционально) оплаты

API уже готов — бот = HTTP-клиент к существующим эндпоинтам.

## Миграция текущих клиентов

Текущие клиенты работают на Xray (старая система, ветка `old`). Нужно:
1. Установить sing-box рядом с Xray на серверах
2. Протестировать новую подписку
3. Перевести клиентов на новый формат (sing-box JSON вместо vless:// ссылок)
4. Убрать Xray

## SQLite → PostgreSQL

SQLite работает для текущего масштаба (десятки серверов, сотни клиентов). При росте до тысяч клиентов или нескольких бэкенд-инстансов — нужна миграция на PostgreSQL.
